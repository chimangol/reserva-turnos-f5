# Reserva de Turnos — Fútbol 5

Este proyecto permite agendar turnos para canchas de fútbol 5 entre las 09:00 y las 23:00 hs, con interfaz moderna.

## 🧰 Tecnologías
- Frontend: HTML + Tailwind + JS
- Backend: Node.js + Express + SQLite
- Hosting: Render (backend) + Vercel (frontend)

## 🚀 Despliegue rápido
1. Subir repo a GitHub.
2. Deploy backend en Render.
3. Deploy frontend en Vercel.
4. Cambiar la URL de `API` en `script.js`.
